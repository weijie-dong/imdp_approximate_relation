# 实验记录：di_medium_5act → di_fine_7act 成对分析

## 日期

2026-06-12 ~ 2026-06-14

## 实验目的

验证 medium_5act (V≈0.69) 与 fine_7act (V≈0.99) 之间的近似仿真关系。期望 coarse (5 个动作) 可通过容差 ε 仿真 fine (7 个动作)，从而将粗糙策略迁移到精细系统上，同时 bound 仍有意义。

## 实验配置

| 参数 | 值 |
|------|-----|
| 粗糙 IMDP | `di_medium_5act` (14×14, 196 states, 5 actions) |
| 精细 IMDP | `di_fine_7act` (21×21, 441 states, 7 actions) |
| f2c 映射 | 几何重叠 (avg ~1.8 coarse/fine cell) |
| coarse 动作 | u ∈ {-5, -2.5, 0, 2.5, 5} |
| fine 动作 | u ∈ {-5, -3.33, -1.67, 0, 1.67, 3.33, 5} |
| eps_tol | 0.001 |
| n_jobs | -1 (全 CPU) |
| mc_iterations | 5000 |
| sim_horizon | 200 |

### 关键观察

- **ε 临界点极窄**: 仅 ε=1.0 和 ε=0.999 可行，ε=0.998 时 R 立即坍塌为 ∅。不存在"随 ε 减小逐步收缩"的渐变过程
- **R 收敛行为**: 当 ε < 0.999 时，R 在一轮固定点迭代中从 784 对骤降到 0（所有 784 对均无法通过 LP 检验）。算法用 46 万次 LP 验证了这一点
- **不可行时也很慢**: ε ≤ 0.998 时虽然 R 为空，但 warm-start 的 784 对仍需逐对检查（每对都要枚举角点+求解 LP），累计 17 小时/轮

| 经验满足概率 | **1.0000** |

| Bound holds | True |

### Step 3 解读

Bound "成立"但完全没有意义：

```
V_fine(s0) ≥ V_coarse(s0_coarse) − (1−(1−ε)^N)
     1.0  ≥    0.6879              −     1.0
     1.0  ≥   −0.3121  (floored to 0)
```

- ε 接近 1 导致 degradation = 1.0（概率损失 100%），理论下界被钳制为 0
- 精细系统自身的 V=0.995 远高于粗糙的 V=0.688，但近似仿真框架无法传递这个优势——反而受限于最大的 ε 惩罚
- 这是 **"没有意义的 bound"** 的典型案例：结果形式上成立，但信息量为零

## 失败原因分析

### 根因：动作集合不匹配

coarse 动作 {-5, -2.5, 0, 2.5, 5} 与 fine 动作 {-5, -3.33, -1.67, 0, 1.67, 3.33, 5} 没有一一对应关系：

```
coarse:  -5    -2.5     0     2.5     5
           │      │      │      │      │
fine:    -5  -3.33 -1.67  0  1.67  3.33  5
```

Algorithm 2 的条件是 ∀a2 (coarse action) ∃a1 (fine action)，耦合 LP 要求 fine 的转移分布能"解释"coarse 的转移分布。当 coarse 动作 -2.5 在 fine 中没有精确匹配时：

- fine 的 -1.67 和 -3.33 都不能产生与 coarse -2.5 相同的转移分布
- 凸组合（随机化策略）理论上可以模拟中间值，但 Algorithm 2 不允许混合动作——每个 coarse 动作必须找一个**单一** fine 动作匹配
- LP 自由度仅在于后继状态的耦合权重分配，无法改变选哪个动作

### 次要因素：几何重叠映射在初始 R 中的信息损失

初始 R 有 784 对（196×441 共 86,436 对中只取了 0.9%）。可能的 valid pair 被几何启发式裁剪掉，但这个实验中 R 在 ε<0.998 时**完全坍塌**（0 对），说明问题不在于少了几对，而是所有 784 对都 fail。

## 后续改进方案

### 方案 1：统一动作集合（最直接）

coarse 和 fine 使用**相同的动作离散化**，消除动作不匹配的根源。

```
推荐配置: medium_7act → fine_7act (同为 7 动作)
  u ∈ {-5, -3.33, -1.67, 0, 1.67, 3.33, 5}
  coarse: 14×14, 196 states
  fine:   21×21, 441 states
```

**预期**:
- V_coarse ≈ 0.85+ (类似 medium_5act 的 0.69 但 7 动作应更高)
- V_fine ≈ 0.995
- ε_min 应显著低于 0.999（因为 ∀a2∃a1 中 a1 可以选相同的动作值）
- 每轮时间应显著缩短（每个 a2 只检查 1 个 a1，而非当前 7 vs 5 的穷举）

**需要先构建**: `di_medium_7act`（14×14 + 7 动作），验证 V 是否 > 0.7。

### 方案 2：允许混合动作匹配（算法改进）

将 Algorithm 2 的条件从 "∃a1" 放宽为 "∃α₁,...,αₖ, ∑αᵢ=1, αᵢ≥0"，即允许 fine 的随机化策略来模拟 coarse 动作。这是混合策略的凸组合，理论上可以精确模拟任何在凸包内的 coarse 动作。

**代价**: LP 变量数增加（需要同时优化动作混合权重和耦合权重），复杂度上升。

### 方案 3：小而统一的动作集 — 3 动作对比

回到最简单的 3 动作设置，验证"相同动作集合"是否足够：

```
di_medium → di_fine (同为 3 动作, u ∈ {-5, 0, 5})
  medium: 14×14, V≈0.31
  fine:   21×21, V≈0.37
```

V 值低但至少动作完全匹配，可以作为"相同动作集是否能得到小 ε"的验证实验。如果这个配置 ε 也很大，说明问题不在动作匹配，而在网格精度差异（1.5× 非整数比导致 coarse cell 的转移间隔跨多个 fine cell）。

### 方案 4：整数比分辨率 + 相同动作

使用整数倍的分辨率，消除几何重叠的启发式信息损失：

```
di_medium → di_medium_x2 (同为 3 动作, 2× 整数比)
  medium:   14×14, V≈0.31
  medium_x2: 28×28, V≈0.46
```

严格 1:1 f2c 映射 + 相同动作，如果这也有大 ε，说明是动力学本身的离散化误差（coarse 的概率区间太宽导致无法被 fine 解释）。

### 方案 5：宽松初始 R（不裁剪）

当前几何重叠只取有空间交叠的 fine-coarse pair，丢弃了约 99% 的可能 pair。对于小状态空间，可以尝试全标签笛卡尔积作为初始 R：

```
medium_5act → fine_7act: 196×441 = 86,436 对
所有 goal/normal/critical 标签一致的 pair 都纳入 R
```

这避免了信息损失，但 LP 数量会爆炸（86k 对 vs 784 对）。仅适合验证"是否存在更合适的 pair 被几何重叠错误裁剪掉了"。

---

## 结论

- 5 动作 vs 7 动作的配对**不成立**（ε > 0.999 才有仿真关系，等于没有）
- 根因是动作集合不匹配，Algorithm 2 的 ∀a2∃a1 条件要求 coarse 动作在 fine 中有对应
- 耗时的关键是 R 坍塌前的**全量 LP 检查**——即使最终 R=∅，仍需枚举角点并解 LP
- 最优先尝试**方案 1**：`di_medium_7act` → `di_fine_7act`，统一 7 动作，预期 ε 显著更小
